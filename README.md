# Lab-Assignment-1-Web-Dev-III-
## Lab Assignment 1 – Web Dev III (Node.js & Express Backend)

## Requirements

- Node.js
- No external npm packages
- No Express
- No database

Only Node.js built-in modules are used.

## 1. CLI Calculator

```bash
node calculator.js add 10 5
node calculator.js subtract 10 5
node calculator.js multiply 10 5
node calculator.js divide 10 5
```

## 2. Custom Modules

```bash
node app.js
```

This demonstrates `module.exports` and `require()` using `isEven.js` and `logger.js`.

## 3. HTTP Server

```bash
node server.js
```

Open:

- http://localhost:3000/
- http://localhost:3000/about
- http://localhost:3000/contact
- Try an invalid route for a 404 response.

Stop the server with `Ctrl + C`.

## 4. File Manager

```bash
node fileManager.js
```

The program creates, reads, updates, and deletes `test.txt`.

## 5. Dice Generator

```bash
node dice.js
```
